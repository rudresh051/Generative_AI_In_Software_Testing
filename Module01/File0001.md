# Syllabus

Generative AI in Software Testing Training

Description

Learn Generative AI for software testing using tools like testRigor to automate planning, requirement analysis, case creation, and closure. Generate synthetic data, interpret results, and streamline QA with AI. Explore real-world cases like healthcare analytics and compare manual vs AI workflows. Includes hands-on demos to boost speed and accuracy. Ideal for testers and QA professionals.

Foundations of Generative AI in Software Testing

Explore GenAI for Software Testing in this hands-on course:

- Understand Testing Life Cycle: Learn the key phases and how GenAI fits into each

- Analyze Requirements: Use GenAI to clarify needs, suggest focus areas, and define acceptance criteria

- Create Test Cases: Automate test case generation using AI tools

- Compare Methods: Explore traditional vs GenAI-based testing workflows

- Practice with Tools: Apply AI tools in demos for smarter, faster testing

Test Design and Data Preparation with GenAI

Explore GenAI for Test Design and Data Preparation in this hands-on course:

- Plan with AI: Use GenAI to streamline and enhance test planning

- Generate Test Cases: Automate test case creation using tools like testRigor

- Create Synthetic Data: Use AI to generate realistic and augmented test datasets

- Prioritize and Document: Automate test case prioritization and documentation

- Apply to Real Projects: See how GenAI supports complex systems like healthcare analytics

Execution and Closure Using GenAI

Explore GenAI for Test Execution and Closure in this hands-on course:

- Set Up Environments: Use GenAI to automate test environment configuration

- Execute Tests: Generate scripts and run tests efficiently with AI tools

- Analyze Results: Interpret test outcomes and reports using GenAI insights

- Automate Closure: Streamline test cycle closure with AI-driven documentation

- Practice with Demos: Optimize execution and reporting through real-world examples

Conclusion

By the end of this course, learners will gain hands-on experience using Generative AI across the software testing lifecycle. They’ll automate requirement analysis, test planning, case creation, execution, and closure with tools like testRigor. Learners will generate synthetic data, prioritize tests, and analyze results using AI, boosting QA speed and accuracy through real-world demos and workflows.
